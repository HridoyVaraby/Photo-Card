# Product Overview

## News Photo Card Generator

A browser-based React application for creating branded social media cards from news photos. Users upload images and logos, add headlines, customize design elements, and export professional-looking cards for social media sharing.

## Core Purpose

Transform news photos into branded social media cards with:
- Main news image as background
- Company logo positioning
- Customizable headline overlays
- Multiple social media format support
- Real-time canvas preview
- PNG/JPEG export capabilities

## Target Use Cases

- News organizations creating social media content
- Journalists sharing stories on social platforms
- Content creators needing branded image cards
- Marketing teams producing consistent visual content

## Key Features

- **Multi-format support**: Twitter cards, Facebook posts, Instagram squares, Stories
- **Brand customization**: Colors, fonts, layouts
- **Multilingual support**: English and Bengali text rendering
- **Real-time preview**: Live canvas updates
- **Export flexibility**: PNG (lossless) or JPEG (compressed) with quality control
- **No backend required**: Fully client-side processing
